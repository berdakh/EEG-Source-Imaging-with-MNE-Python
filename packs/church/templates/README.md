# Templates

Put the church's letterhead here as `letterhead.docx` (a Word file with the
header and footer set up, body empty). Workflows that output `docx` with
`template: letterhead.docx` will write into a copy of it. If the file is
missing, a plain document is produced instead.

Templates are per installation and may contain the client's branding, so they
are not committed to git beyond this README.
